# ❓ F.A.Q — Vinted Favorites Manager

## 📌 Général

### À quoi sert Vinted Favorites Manager ?
Vinted Favorites Manager permet de nettoyer vos favoris Vinted en supprimant automatiquement les articles qui ne sont plus disponibles.

L'outil détecte les articles favoris qui ont été vendus ou supprimés afin de vous permettre de les retirer facilement de votre liste.

---

### Est-ce que l'outil supprime mes propres articles vendus ?
Non.

L'outil ne concerne pas vos propres annonces.  
Il agit uniquement sur les articles que **vous avez ajoutés en favoris** et qui ne sont plus disponibles sur Vinted.

---

### Est-ce que l'outil fait la même chose que les bots qui ajoutent automatiquement des favoris ?
Non.

L'objectif est différent :
- Certains outils permettent d'automatiser l'ajout de favoris.
- Vinted Favorites Manager permet de **nettoyer vos favoris en retirant les articles vendus ou supprimés**.

L'outil ne cherche pas à remplacer d'autres solutions existantes, mais à proposer une fonctionnalité complémentaire, simple et accessible.

---

## ⚙️ Utilisation

### Est-ce compliqué à utiliser ?
Non.

Le fonctionnement a été pensé pour être le plus simple possible :

1. Ouvrir la page de vos favoris Vinted.
2. Ouvrir la console du navigateur.
3. Copier/coller le code fourni dans le tutoriel.
4. Appuyer sur Entrée.
5. Laisser l'outil fonctionner automatiquement.

Vous n'avez aucune modification de code à faire.

---

### J'ai peur des lignes de code, est-ce dangereux ?
Pas d'inquiétude.

Le code est simplement exécuté **localement dans votre navigateur**.

Vous n'avez rien à modifier :
- vous copiez le code,
- vous le collez,
- vous lancez l'exécution.

Une fois terminé, vous pouvez fermer la console du navigateur.

---

### Que se passe-t-il pendant l'utilisation ?
Une fois lancé :

- L'outil analyse vos favoris.
- Il détecte les articles vendus ou supprimés.
- Une petite fenêtre apparaît avec la liste des articles concernés.
- Les articles sont déjà sélectionnés par défaut.
- Vous cliquez simplement sur **"Supprimer"**.
- L'outil retire les favoris sélectionnés.

Une fois terminé, un message vous indique de recharger la page.

---

### Combien de temps prend le nettoyage ?
Cela dépend du nombre de favoris à analyser.

Exemples :
- Quelques dizaines de favoris : rapide.
- Plusieurs centaines ou plus de 1000 favoris : cela peut prendre plus de temps.

Laissez simplement l'outil travailler sans fermer la page.

---

## 🔒 Sécurité

### Est-ce que l'outil envoie mes données sur un serveur ?
Non.

Le script fonctionne directement dans votre navigateur.

Aucune donnée n'est envoyée vers un serveur externe.

---

### Est-ce que l'outil peut endommager mon ordinateur ?
Non.

Le script agit uniquement sur la page Vinted ouverte dans votre navigateur.

Il ne modifie pas vos fichiers, vos paramètres ou votre ordinateur.

---

### Dois-je donner mon mot de passe Vinted ?
Non.

L'outil utilise uniquement votre session Vinted déjà ouverte dans votre navigateur.

Ne partagez jamais votre mot de passe.

---

## 🐛 Problèmes

### L'outil ne fonctionne pas, que faire ?
Vérifiez que :
- vous êtes connecté à Vinted ;
- vous êtes bien sur la page de vos favoris ;
- vous avez correctement copié tout le code ;
- vous avez suivi toutes les étapes du tutoriel.

Si le problème continue, ouvrez une issue GitHub.

---

### J'ai beaucoup de favoris, l'outil est bloqué ?
Avec un très grand nombre de favoris, l'analyse peut prendre du temps.

Laissez simplement le script terminer son travail.

---

### Pourquoi avoir créé cet outil ?
L'objectif était de créer un outil simple, gratuit et facile à utiliser pour les vendeurs Vinted qui souhaitent nettoyer leurs favoris.

Le but n'est pas de concurrencer d'autres outils existants, mais d'apporter une fonctionnalité complémentaire.
